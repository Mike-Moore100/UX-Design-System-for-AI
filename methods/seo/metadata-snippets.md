# Metadata and Snippets

## What
Metadata and Snippets shape how a page appears in search results and link previews.

Metadata should make the page's value clear before the click.

## Why it matters
Search result appearance influences click quality and user expectation.

Good metadata:
- clarifies relevance
- improves qualified clicks
- sets accurate expectations
- supports sharing
- reduces mismatch between search result and page

Metadata is a promise the page must keep.

## When to apply
- public pages
- product pages
- blog posts
- docs
- landing pages
- comparison pages
- pages shared on social platforms

## How to apply

- write a specific title
- write a useful meta description
- align metadata with page content
- use Open Graph and social metadata where relevant
- avoid duplicate titles across important pages
- keep snippets honest and user-centred

The search result should make the right user want the page.

## Implementation rules

- title must identify the page and primary value
- description must summarize usefulness, not stuff keywords
- metadata must not promise content the page lacks
- canonical URL must be correct when relevant
- social preview title and image must match page intent
- important pages must not have missing or duplicated metadata

## Example

Bad:
- "Home"
- duplicated title tags
- keyword-stuffed description
- social preview with irrelevant image

Good:
- specific title and page promise
- concise description matching user intent
- accurate Open Graph data
- canonical URL set correctly

## Fail conditions

- title is vague or duplicated
- description misleads users
- metadata does not match page content
- social previews look broken
- canonical signals are missing or wrong

## Enforcement rule

If metadata creates the wrong expectation, rewrite it until the snippet matches the page's real value.
