# Search Intent Alignment

## What
Search Intent Alignment ensures a page satisfies what the searcher is actually trying to learn, compare, decide, or do.

The page must match the user's intent before it can perform in search.

## Why it matters
Search engines reward pages that satisfy user intent.

Strong intent alignment:
- improves relevance
- reduces bounce
- supports useful content
- clarifies page structure
- increases qualified traffic

Ranking without satisfying intent is not success.

## When to apply
- landing pages
- product pages
- feature pages
- blog posts
- documentation
- comparison pages
- category pages

## How to apply

- identify whether intent is informational, commercial, navigational, or transactional
- answer the primary query early
- structure content around the user's decision path
- avoid forcing marketing copy where the user needs information
- include proof, examples, or next steps where relevant
- remove content that does not support the intent

The page should feel like the obvious answer to the query.

## Implementation rules

- page title must reflect the primary intent
- h1 must align with the page promise
- opening content must confirm relevance quickly
- content sections must map to likely user questions
- CTA must match the searcher's stage
- avoid keyword stuffing or irrelevant content blocks

## Example

Bad:
- searcher wants comparison, page only gives a generic pitch
- title promises a guide, page is a sales page
- content hides the answer below vague intro copy

Good:
- query answered early
- sections match user questions
- CTA fits intent stage
- examples and proof support decision-making

## Fail conditions

- page does not answer the likely query
- page promise and content mismatch
- CTA asks for too much too early
- content is generic or padded
- keywords are present but usefulness is weak

## Enforcement rule

If the page does not satisfy the searcher's intent, restructure the content before optimising metadata.
