# Image SEO

## What
Image SEO makes visual assets discoverable, accessible, fast, and useful to the surrounding content.

Images should support comprehension, not only decorate the page.

## Why it matters
Images influence performance, accessibility, and search understanding.

Good image SEO:
- improves page speed
- supports image search
- strengthens topical relevance
- improves accessibility
- makes content more useful

Large, unlabeled, irrelevant images weaken the page.

## When to apply
- articles
- product pages
- documentation
- ecommerce pages
- case studies
- galleries
- landing pages

## How to apply

- use descriptive filenames where practical
- write alt text for informative images
- leave decorative images empty or hidden from assistive tech
- compress images and serve modern formats
- define width and height to reduce layout shift
- lazy-load below-the-fold images
- place images near relevant copy

Images should make the page clearer and faster.

## Implementation rules

- informative images must have useful alt text
- decorative images must not create accessibility noise
- critical images must not be excessively large
- dimensions must be reserved to avoid layout shift
- image content must match surrounding headings and copy
- avoid text-only information locked inside images

## Example

Bad:
- file named image-final-2.png
- alt text says "picture"
- huge hero image slows LCP
- chart information is unavailable in text

Good:
- descriptive filename
- meaningful alt text
- responsive image sizes
- chart summary in nearby text
- stable dimensions

## Fail conditions

- images slow the page unnecessarily
- alt text is missing or useless
- decorative images are announced
- visual information is inaccessible
- images do not support the page intent

## Enforcement rule

If an image does not improve understanding, accessibility, or trust, optimise it, replace it, or remove it.
