# Clarity First

## What
Clarity First means copy should be understood instantly before it tries to be clever, emotional, or distinctive.

Clear copy reduces cognitive load.

## Why it matters
Users scan interfaces under time pressure.

Clear copy:
- improves comprehension
- reduces hesitation
- supports accessibility
- increases trust
- makes actions easier

If the user has to decode the copy, the interface slows down.

## When to apply
- headlines
- CTAs
- forms
- onboarding
- empty states
- error messages
- navigation labels

## How to apply

- use familiar words
- put the main idea first
- remove vague modifiers
- replace abstract claims with concrete outcomes
- keep sentences short where possible
- preserve necessary detail when it prevents confusion

The user should understand the message on the first scan.

## Implementation rules

- avoid cleverness that hides meaning
- avoid inflated adjectives without evidence
- use active voice when it improves clarity
- write labels that match user intent
- remove duplicate ideas
- do not shorten copy until meaning remains intact

## Example

Bad:
- "Unlock your potential"
- "Proceed"
- "Something went wrong"
- vague navigation labels

Good:
- "Create your project"
- "Send password reset link"
- "We could not save changes. Try again."
- labels matching the destination

## Fail conditions

- user has to reread
- copy sounds impressive but means little
- CTA outcome is unclear
- error copy does not guide recovery
- labels do not match the user's goal

## Enforcement rule

If copy is not immediately understandable, rewrite it for meaning before style.
