# CTA Copy

## What
CTA Copy labels the action the user is about to take.

Good CTA copy makes the next step specific, honest, and easy to choose.

## Why it matters
The CTA is often the final point of hesitation.

Strong CTA copy:
- clarifies outcome
- reduces uncertainty
- supports conversion
- prevents misclicks
- builds trust

The button should set the right expectation.

## When to apply
- primary buttons
- secondary actions
- forms
- checkout
- onboarding
- empty states
- destructive actions

## How to apply

- start with a clear verb
- name the outcome when useful
- avoid generic labels when the action is specific
- keep labels short but meaningful
- match CTA copy to the destination
- use risk-aware copy for sensitive actions

The user should know what happens after clicking.

## Implementation rules

- primary CTA must describe the primary action
- destructive CTAs must name the destructive action
- form submit buttons must reflect what is being submitted
- vague labels like "Submit" should be replaced when possible
- CTA copy must not overpromise
- secondary CTA labels must be clearly distinct

## Example

Bad:
- "Submit"
- "Go"
- "Click here"
- "Yes"

Good:
- "Create account"
- "Start free trial"
- "Send invite"
- "Delete workspace"

## Fail conditions

- CTA outcome is unclear
- CTA label does not match the next screen
- action risk is hidden
- primary and secondary CTAs feel similar
- copy is clever but ambiguous

## Enforcement rule

If the CTA does not clearly describe the action or outcome, rewrite it before changing the button design.
