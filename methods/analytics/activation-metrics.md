# Activation Metrics

## What
Activation Metrics identify the earliest measurable moment when a user experiences meaningful product value.

Activation should measure value reached, not account created.

## Why it matters
Signups do not prove users are becoming successful.

Strong activation metrics:
- focus teams on time to value
- reveal onboarding friction
- improve retention prediction
- connect product work to outcomes
- reduce vanity reporting

A product can grow signups while failing activation.

## When to apply
- onboarding
- free trials
- product-led growth
- dashboards
- first-run experiences
- team setup
- AI generation flows

## How to apply

- define the user action that indicates first real value
- distinguish setup completion from value realization
- measure time to activation
- track the steps that lead to activation
- segment by audience or acquisition source where useful
- avoid choosing a metric only because it is easy to count

The metric should represent a user becoming more likely to return.

## Implementation rules

- activation metric must connect to user value
- the event must be observable and reliable
- setup milestones must not be mistaken for activation
- time-to-value must be tracked when relevant
- activation should be segmented by meaningful user type
- metric definitions must be documented

## Example

Bad:
- activation equals account created
- activation equals first login
- metric is chosen because it is already tracked
- team cannot explain why activation predicts value

Good:
- project created and first teammate invited
- first report generated and shared
- first AI draft accepted or edited
- time from signup to first useful output tracked

## Fail conditions

- metric does not reflect value
- event fires before the user succeeds
- activation cannot be measured reliably
- time to value is unknown
- teams optimise signup instead of success

## Enforcement rule

If activation is defined as account creation, replace it with the earliest measurable value moment.
