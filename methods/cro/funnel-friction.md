# Funnel Friction

## What
Funnel Friction is any unnecessary effort, uncertainty, step, field, or delay between user intent and conversion.

Every extra requirement must earn its place.

## Why it matters
Users abandon when the path feels longer, riskier, or more confusing than expected.

Reducing funnel friction:
- increases completion
- improves perceived speed
- reduces decision fatigue
- makes value easier to reach
- lowers support burden

Friction should be intentional, not accidental.

## When to apply
- signup
- onboarding
- checkout
- trials
- demo booking
- lead capture
- plan selection

## How to apply

- remove unnecessary fields
- defer non-essential questions
- show progress when flows take multiple steps
- keep related inputs together
- explain why sensitive information is needed
- preserve user input across errors

The user should feel constant forward momentum.

## Implementation rules

- ask only for information needed now
- make optional fields clearly optional
- avoid account creation before value when possible
- keep errors recoverable in place
- do not repeat information requests
- use defaults and smart detection responsibly

## Example

Bad:
- long signup form before value
- asking company size, phone, and role too early
- errors clear the form
- unclear multi-step process

Good:
- minimum fields to start
- optional enrichment after activation
- visible progress
- preserved input and inline recovery

## Fail conditions

- user must provide unnecessary information
- flow asks for commitment too early
- progress is unclear
- errors force rework
- steps feel disconnected from value

## Enforcement rule

If a step does not directly support conversion, trust, or required operation, remove it or defer it.
