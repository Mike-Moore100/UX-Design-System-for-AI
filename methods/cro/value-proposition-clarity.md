# Value Proposition Clarity

## What
Value Proposition Clarity makes the core promise obvious: who it is for, what it helps them do, and why it matters now.

The value must be understood before the user is asked to act.

## Why it matters
Users do not convert when they cannot quickly understand relevance.

Clear value:
- reduces hesitation
- improves attention
- increases perceived relevance
- supports stronger CTAs
- makes comparison easier

Confusion is conversion friction.

## When to apply
- landing pages
- hero sections
- pricing pages
- signup flows
- product launches
- feature pages

## How to apply

- state the user and outcome clearly
- connect the product to a concrete job or pain
- avoid vague category language
- support the claim with proof or specificity
- make the primary action the logical next step
- remove competing promises

The user should know "this is for me" within seconds.

## Implementation rules

- headline must communicate the core offer or category
- supporting copy must explain the outcome
- CTA must match the promise
- proof must support the main claim
- avoid jargon unless the audience expects it
- do not hide the value behind feature lists

## Example

Bad:
- "The future of productivity"
- vague hero copy
- CTA disconnected from the promise
- features listed before value is clear

Good:
- specific user outcome
- clear product category
- proof close to the claim
- CTA that continues the intent

## Fail conditions

- user cannot tell who it is for
- value is abstract or generic
- CTA appears before the promise is understood
- proof does not support the claim
- multiple promises compete

## Enforcement rule

If the user cannot repeat the value in one sentence, clarify the promise before optimising anything else.
