# Commitment Consistency

## What
Commitment Consistency uses small, meaningful actions to help users progress toward a larger goal.

Each commitment should deepen intent without trapping the user.

## Why it matters
People are more likely to continue when the next step is consistent with a choice they already made.

Good commitment design:
- improves activation
- reduces first-step friction
- increases completion
- makes progress feel earned
- supports onboarding momentum

The first action often determines whether the user continues.

## When to apply
- onboarding flows
- lead capture
- account setup
- trial activation
- product tours
- multi-step forms
- upgrade paths

## How to apply

- ask for the smallest useful first commitment
- make every step visibly connected to the user's goal
- preserve progress between steps
- use prior answers to personalise later steps
- avoid asking for high-effort information too early
- let users revise or exit without penalty

The next step should feel like a natural continuation, not a new demand.

## Implementation rules

- first step must be low-friction and meaningful
- progress indicators must reflect real progress
- later asks must be justified by earlier intent
- saved answers must reduce future effort
- users must be able to change previous inputs
- avoid bait-and-switch commitments

## Example

Bad:
- asks for payment before value is clear
- first step requires unnecessary company data
- progress resets when user goes back
- later steps feel unrelated to the initial promise

Good:
- small first action tied to user outcome
- visible progress
- answers reused to personalise setup
- larger commitment appears after value is established

## Fail conditions

- early commitment is too large
- steps are not connected
- progress feels artificial
- user cannot revise choices
- commitment is used to pressure rather than guide

## Enforcement rule

If the first commitment feels heavier than the value already earned, reduce the ask or move it later.
