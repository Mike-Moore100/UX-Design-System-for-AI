# Ethical Urgency

## What
Ethical Urgency helps users act when timing genuinely matters.

Urgency must be based on a real constraint, deadline, availability limit, or user benefit.

## Why it matters
Users delay decisions when there is no clear reason to act now.

Ethical urgency:
- clarifies timing
- reduces procrastination
- improves campaign performance
- supports time-sensitive offers
- preserves trust

Fake urgency may lift short-term clicks while damaging long-term credibility.

## When to apply
- launches
- limited enrollment
- event registration
- expiring offers
- inventory-limited products
- trial onboarding
- renewal flows

## How to apply

- state the real reason timing matters
- make deadlines specific
- explain what changes after the deadline
- place urgency close to the relevant action
- use reminders without pressure loops
- remove countdowns or scarcity claims that are not true

The user should understand the consequence of waiting.

## Implementation rules

- urgency claims must be accurate
- deadlines must include date or clear timing
- scarcity must reflect actual availability
- copy must avoid shame, panic, or coercion
- urgency should support the user's goal
- do not reset countdowns to create false pressure

## Example

Bad:
- countdown timer restarts on refresh
- "Only 2 spots left" without a real capacity limit
- aggressive modal blocks exit
- vague "Act now" with no reason

Good:
- real enrollment deadline
- specific offer end date
- clear explanation of what changes
- calm CTA that helps the user decide

## Fail conditions

- urgency is invented
- user cannot verify what happens next
- pressure overrides informed choice
- urgency hides important terms
- copy creates anxiety unrelated to user value

## Enforcement rule

If urgency is not truthful, specific, and useful to the user, remove it or replace it with a real timing reason.
