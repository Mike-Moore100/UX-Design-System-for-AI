# Von Restorff Effect

## What
The Von Restorff Effect means an item that visually or conceptually stands apart is more likely to be noticed and remembered.

Distinctiveness directs attention.

## Why it matters
Users scan quickly and miss items that blend into the interface.

Useful distinction:
- highlights priority
- improves recall
- supports primary actions
- helps warnings stand out
- reduces choice confusion

Distinctiveness must be reserved for what matters.

## When to apply
- primary CTAs
- featured plans
- alerts
- onboarding steps
- empty states
- important changes
- comparison tables

## How to apply

- make only the priority item distinct
- use contrast, size, spacing, or label changes intentionally
- keep secondary options visually quieter
- avoid making every card or button special
- use distinction to support the user's decision
- preserve accessibility and readability

The distinct item should be the item users should notice.

## Implementation rules

- one primary element should stand out per decision area
- distinction must support user priority
- warnings must stand out without overwhelming unrelated content
- featured plans must explain why they are featured
- decorative distinction must not compete with actions
- do not overuse badges, colour, or motion

## Example

Bad:
- every card has a badge
- decorative icon is more prominent than CTA
- warning looks like normal helper text

Good:
- recommended plan is clearly distinct
- primary CTA has strongest contrast
- destructive warning is visually separate
- new important status stands out briefly

## Fail conditions

- everything appears special
- the wrong element gets attention
- distinction is decorative only
- highlighted item lacks explanation
- accessibility suffers from styling

## Enforcement rule

If an element stands out, it must deserve attention and help the user decide or act.
