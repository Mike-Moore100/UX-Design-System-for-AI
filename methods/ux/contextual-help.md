# Contextual Help

## What
Contextual Help gives users guidance at the moment and place they need it.

Help should be close to the problem.

## Why it matters
Users rarely stop their task to read documentation.

Contextual help:
- reduces confusion
- prevents errors
- supports learning
- improves completion
- keeps users in flow

The right help at the right moment beats a large help centre.

## When to apply
- complex forms
- settings
- new features
- dashboards
- permissions
- errors
- AI-generated outputs

## How to apply

- place help near the related control
- keep guidance short and specific
- reveal more detail only when requested
- use examples for unfamiliar inputs
- link to deeper docs when needed
- avoid interrupting expert users

Help should answer the user's current question.

## Implementation rules

- helper text must be attached to the relevant element
- tooltips must not hide essential information
- examples must be realistic
- help must be accessible by keyboard and screen reader
- documentation links must preserve user context where possible
- do not use help text to compensate for unclear UI

## Example

Bad:
- generic help link in the footer
- tooltip required to understand a field
- long instructional modal before the task

Good:
- short helper text under a complex field
- example input shown in context
- expandable explanation for advanced settings
- error message links to recovery guidance

## Fail conditions

- user must leave the flow to understand a control
- help is too generic
- tooltip contains essential information only
- guidance appears too early or too late
- help is inaccessible

## Enforcement rule

If users need help, provide it where the question occurs and keep the primary flow moving.
