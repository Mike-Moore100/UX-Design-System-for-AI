# Problem Agitation Solution

## What
Problem Agitation Solution structures messaging around a clear pain, the cost of leaving it unresolved, and the product's path to relief.

Agitation should clarify stakes, not exploit anxiety.

## Why it matters
Users act when they understand both the problem and the cost of inaction.

Effective PAS:
- increases relevance
- makes value concrete
- improves emotional clarity
- supports persuasive flow
- helps users recognise their situation

Skipping the problem makes the solution feel optional.

## When to apply
- landing pages
- sales pages
- campaign copy
- emails
- ads
- product launches
- feature messaging

## How to apply

- state the user's problem in familiar language
- show the practical cost or consequence
- avoid exaggerating or shaming
- connect the solution directly to the pain
- prove the solution can work
- make the next action feel like relief or progress

The user should feel accurately understood before being sold to.

## Implementation rules

- problem must be specific to the audience
- agitation must be truthful and proportionate
- solution must address the named pain
- proof must support the claimed relief
- CTA must continue the problem-solving path
- avoid fear-based manipulation

## Example

Bad:
- vague problem like "work is hard"
- exaggerated consequences
- solution does not address the pain
- CTA appears before relevance is built

Good:
- specific pain
- realistic consequence
- product mechanism explained
- proof and CTA tied to relief

## Fail conditions

- problem is generic
- agitation feels manipulative
- solution is disconnected
- proof is missing
- user feels pressured rather than understood

## Enforcement rule

If the problem, consequence, and solution do not form one clear chain, rewrite the message before improving visual presentation.
