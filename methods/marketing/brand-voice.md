# Brand Voice

## What
Brand Voice defines how a product sounds across touchpoints while preserving clarity, trust, and audience fit.

Voice should make the product recognisable without making the message harder to understand.

## Why it matters
Consistent voice builds memory and trust.

Strong brand voice:
- improves recognition
- strengthens emotional fit
- keeps teams consistent
- prevents generic messaging
- supports differentiated experience

Inconsistent voice makes a product feel less mature.

## When to apply
- websites
- product UI
- onboarding
- emails
- error messages
- social content
- sales collateral

## How to apply

- define voice attributes in practical terms
- pair each attribute with do and do-not examples
- adapt tone to user context and emotion
- preserve clarity over cleverness
- keep high-stakes copy calm and direct
- audit repeated touchpoints for consistency

The product should sound like one coherent team.

## Implementation rules

- voice must support the user's task
- tone must adapt to context
- error and security copy must prioritise clarity
- examples must guide real writing decisions
- voice must not justify jargon or vagueness
- copy should remain accessible and plain where needed

## Example

Bad:
- playful error when user lost work
- formal legal tone in onboarding
- slogan-heavy homepage with unclear meaning
- different teams write in conflicting styles

Good:
- confident homepage language
- calm support copy
- direct security copy
- consistent word choices across UI and marketing

## Fail conditions

- voice reduces comprehension
- tone ignores user emotion
- brand language changes by surface
- copy sounds generic
- cleverness replaces usefulness

## Enforcement rule

If brand voice competes with clarity or user trust, adjust the tone while preserving the core message.
