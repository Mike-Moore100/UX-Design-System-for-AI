# Visual Weight

## What
Visual Weight is the perceived importance of elements based on size, contrast, colour, spacing, position, and density.

Heavier elements attract more attention.

## Why it matters
Users scan by weight before reading details.

Good visual weight:
- guides attention
- clarifies hierarchy
- reduces competition
- improves decision speed
- makes priority feel obvious

Every element should have the weight its role deserves.

## When to apply
- CTAs
- cards
- pricing plans
- navigation
- dashboards
- forms
- status states

## How to apply

- give the primary action the strongest useful weight
- reduce secondary elements
- use whitespace to increase importance
- avoid heavy decoration
- balance dense areas with quiet areas
- make danger and warning states visible but controlled

The eye should land where the user needs to act.

## Implementation rules

- primary elements must visually outweigh secondary elements
- decorative elements must remain visually light
- dense content needs clear focal anchors
- warnings must be heavier than neutral text
- disabled states must be lighter but readable
- do not make every element bold, bright, or large

## Example

Bad:
- secondary links look like primary CTAs
- decorative badges dominate the card
- all headings have the same weight

Good:
- one clear dominant action
- quiet supporting content
- strong but restrained warning state
- visible hierarchy through weight

## Fail conditions

- wrong element gets attention
- everything feels equally important
- visual emphasis is decorative
- primary action is visually weak
- dense areas lack hierarchy

## Enforcement rule

If visual weight does not match user priority, rebalance emphasis until the intended path is obvious.
