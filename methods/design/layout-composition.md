# Layout Composition

## What
Layout Composition is the arrangement of content, actions, and supporting elements into a clear visual structure.

Composition decides where attention goes.

## Why it matters
Poor composition makes users work to understand the screen.

Strong composition:
- creates an obvious focal point
- supports scanning
- connects content to action
- reduces visual competition
- makes the interface feel intentional

## When to apply
- full screens and pages
- dashboards and workspaces
- marketing sections
- forms and flows
- responsive layouts
- any screen with multiple content groups

## How to apply

- place the most important content where attention naturally starts
- align related elements to a clear grid
- keep primary actions close to the decision they complete
- use layout to separate primary, secondary, and supporting content
- avoid scattering related controls across the screen
- preserve clear composition across responsive breakpoints

Users should know where to look and what to do next.

## Implementation rules

- one primary focal area per screen
- primary content and primary action must be visually connected
- alignment must be consistent across sections
- secondary content must not interrupt the main path
- responsive changes must preserve priority and meaning
- avoid layouts where every region has equal weight

## Example

Bad:
- primary action far from the decision point
- content blocks arranged with equal emphasis
- layout changes break hierarchy on mobile
- controls are scattered across unrelated areas

Good:
- clear focal area
- supporting content grouped around the main decision
- primary action placed where the user is ready to act
- responsive layout preserves the same priority

## Fail conditions

- user does not know where to start
- primary action feels disconnected
- layout creates competing focal points
- responsive views change the intended hierarchy
- important content is visually buried

## Enforcement rule

If composition does not guide attention toward the primary action, restructure the layout before changing visual style.
