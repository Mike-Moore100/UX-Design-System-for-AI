# Methods Index

Use this file to choose the right Layr methods for the task.

Do not apply every method to every screen.
Select only the methods that materially improve the user's current goal.

---

## Universal Methods

Use these on nearly every UI task:

- `visual-hierarchy.md` - make the main thing obvious
- `cognitive-load-theory.md` - reduce mental effort
- `fitts-law.md` - make interaction fast and accurate
- `signal-to-noise.md` - remove visual and content noise
- `affordance.md` - make interactive elements self-evident
- `feedback-loops.md` - make actions visibly respond

## Selection Rule

Pick 3-6 methods for normal tasks.
Pick more only for large flows or full-page redesigns.

If two methods conflict, choose the one that better supports the user's primary action.
