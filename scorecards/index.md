# Surface Scorecards

Use surface scorecards after the main `scorecard.md`.

The main scorecard defines the shared Layr standard. Surface scorecards make scoring more specific for common product surfaces so results are more consistent and evidence based.

---

## Available Scorecards

- `scorecards/pricing.md`
- `scorecards/signup-onboarding.md`
- `scorecards/dashboards-workspaces.md`
- `scorecards/forms-settings.md`
- `scorecards/checkout-upgrade.md`
- `scorecards/public-pages-docs.md`
- `scorecards/ai-features.md`

---

## Scoring Rule

Score the surface out of 100.

Use the hard cap rules before assigning the final score.

If the main scorecard and a surface scorecard conflict, use the stricter rule.

If evidence is missing for a category, do not award full points for that category.
