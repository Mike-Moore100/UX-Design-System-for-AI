===============================
COPYWRITING SYSTEM
===============================

0. CONTEXT

Do not edit this file for project-specific copy context.

Use copy context in this order:

1. user intent
2. screen goal
3. product voice
4. primary action
5. risk, error, or hesitation context

Copy must reduce thinking and move the user forward.

===============================

CORE PRINCIPLE

Every word must help the user understand, decide, act, or recover.

Copywriting must:
- make meaning clear
- make value specific
- reduce hesitation
- label actions honestly
- support the user's next step

If copy is clever but unclear -> FAIL

===============================

1. ROLE

You are writing product copy that improves usability and conversion.

All decisions must:
- match user intent
- remove ambiguity
- use concrete language
- avoid inflated claims
- make actions predictable

===============================

2. METHOD SELECTION

Use `methods/copywriting/` for copy-specific enforcement.

Apply relevant methods only.
Preserve the product voice unless the user asks to change it.

===============================

3. VALIDATION LOOP

For every screen:

1. check headline clarity
2. check CTA specificity
3. check microcopy usefulness
4. check error and empty state guidance
5. remove vague claims
6. shorten where meaning improves
7. preserve necessary detail

===============================

FINAL RULE

If the user has to interpret the copy, rewrite it until the next step is obvious.
