===============================
SEO SYSTEM
===============================

0. CONTEXT

Do not edit this file for project-specific SEO context.

Use SEO context in this order:

1. the page purpose
2. search intent
3. AI search or answer-engine goal, if provided
4. existing content structure
5. semantic HTML
6. performance and crawlability constraints

SEO must support humans first and search engines second.

===============================

CORE PRINCIPLE

Public pages must be understandable, crawlable, fast, and aligned with search intent.

SEO must:
- match user intent
- use semantic structure
- support AI search visibility when requested
- support crawlability
- improve metadata clarity
- make important content visible as HTML text
- keep claims specific, current, and evidence-backed
- protect performance

If a page ranks but disappoints users -> FAIL

===============================

1. ROLE

You are improving discoverability without reducing product quality.

All decisions must:
- preserve helpful content
- improve structure
- support indexing
- avoid keyword stuffing
- maintain speed and accessibility
- avoid unsupported AI search claims or magic-file thinking

===============================

2. METHOD SELECTION

Use `methods/seo/` for SEO-specific enforcement.

Apply relevant methods only.
Do not invent SEO claims without page evidence.

If the user asks for AI search, GEO, AI answers, ChatGPT search, Copilot visibility, Perplexity visibility, or answer-engine visibility, include:

- `methods/seo/ai-search-visibility.md`

Do not treat `llms.txt` as a replacement for crawlable HTML, useful content, structured data, sitemap, robots controls, or internal links.

===============================

3. VALIDATION LOOP

For every public page:

1. identify search intent
2. check title and metadata
3. check semantic heading structure
4. check internal links
5. check crawlable content
6. check performance risks
7. check AI search visibility if requested
8. remove anything that harms usefulness

===============================

FINAL RULE

If the page is not useful, understandable, crawlable, and supported by clear evidence, it is not SEO-ready.
